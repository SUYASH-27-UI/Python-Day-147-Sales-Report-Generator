# Python Day 147 - Sales Report Generator

## Description
A Python Sales Report Generator that reads sales information from a CSV file and calculates revenue, product sales and best-selling products.

## Features
- Read sales data from CSV
- Calculate total revenue
- Calculate total products sold
- Find the best-selling product
- Calculate product-wise revenue
- Generate a text report

## Files
- `sales_report.py` - Main Python program
- `sales.csv` - Sales data
- `sales_report.txt` - Generated report

## How to Run
Keep `sales_report.py` and `sales.csv` in the same folder.

Run:

`python sales_report.py`

## Concepts Used
- CSV File Handling
- Collections Module
- Dictionary Operations
- Data Analysis
- File Writing
- Exception Handling
